# Futuristic Table Tennis Website

A fun, futuristic-themed website about table tennis, featuring animations, information, and a mini pong game.

## Features

- Futuristic space-themed design with neon colors and animations
- Information about table tennis rules and legendary players
- Animated paddle and ball demonstration
- Interactive mini pong game
- Responsive design

## Sections

- **About**: Introduction to table tennis with animated elements
- **Rules**: Basic rules of the game
- **Players**: Profiles of famous table tennis players
- **Mini Game**: Simple pong game controlled with mouse

## Usage

Open `index.html` in a web browser. Use the navigation buttons to switch between sections. In the Mini Game section, click the canvas to start playing pong.

## Files

- `index.html`: Main HTML structure
- `style.css`: Futuristic CSS styling with animations
- `script.js`: JavaScript for section switching and pong game

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- JavaScript (Canvas API for the game)
